## Hi, I'm Buğra 👋

Infrastructure-minded developer. I've been working in the hosting industry since 2017, and since 2023 I've been on the infrastructure side at a hosting provider.

I like building a system, automating it, and then figuring out how someone might break it.

### What I do

- 🖥️ **Run infrastructure:** Linux servers, VMware ESXi virtualization, web servers and the day-to-day work that keeps production up
- ⚙️ **Automate and integrate:** WHMCS modules and payment gateway integrations in PHP, internal tools in TypeScript and Node.js
- 🛡️ **Learn to defend what I run:** Linux hardening, log analysis and network fundamentals

### Currently focused on

Moving from managing servers by hand to managing them as code: **Docker, CI/CD, Kubernetes and Terraform**, with security built in from the start.
